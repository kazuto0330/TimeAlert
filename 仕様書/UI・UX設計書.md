# UI・UX設計書 (Time Alert)

## 1. 全体画面構成（サイドパネル）
メインUIはChromeの**サイドパネル**（`chrome.sidePanel`）内で提供される。横幅一杯を使用する。

### 1.1. 共通レイアウトとデザイン方針
- **デザインスタイル:** 現在主流のモダンなフラットデザイン、またはニューモーフィズム要素を取り入れたクリーンなUI。十分な余白（パディング）、角丸（border-radius）、控えめなシャドウを用いて洗練された印象を与える。
- **カラーパレット:** アクセントカラーに**オレンジ**を採用。再生ボタン、トグルボタンのON状態、アクティブなタブ表示などにオレンジを使用し、視覚的なコントラストとアクションを促す。
- **ヘッダー部:** タブ切り替え（「タイマー」 / 「アラーム」）および**設定画面を開くためのボタン（歯車アイコン等）**を配置。
- **アクティブアイテムヘッダー:** 有効なタイマーやアラームが存在する場合、タブの直下にアクセントカラーを背景色とした目立つヘッダーを表示する。タイトル、大きな文字での残り時間、停止（⏹）ボタンを配置し、現在進行中のタスクを常に確認・操作できるようにする。
- **メインコンテンツ部:** カードリスト領域（縦スクロール）。スクロールバーは全体のモダンなデザインに合わせた細身で角丸のカスタムデザイン（Webkit標準拡張）を適用する。スクロールバーの出現によってカードの横幅が変動しないよう、常にスクロール用のガター（余白）を確保する。また、スクロール最下部でも新規追加ボタン（FAB）と最後のカードが被らないよう、下部にカード約1枚分の十分な余白を設ける。
- **フローティングアクション:** 右下固定の「＋」ボタン（新規カード追加）。アクセントカラーのオレンジを目立たせる。

### 1.2. テーマ
- ライトモードとダークモードの2種類を作成。
- デフォルトはOSまたはブラウザのシステム既定値（`prefers-color-scheme`）に自動で追従する。

### 1.3. 設定画面（オプションページ）
- **表示方式:** サイドパネルのヘッダーにある設定ボタン（歯車アイコン等）を押下すると、別タブで専用の設定ページ（オプションページ）が開く。
- **レイアウト:** 画面左側に「一般」「外観」「サウンド」のタブナビゲーションを縦に配置し、右側に選択したタブの各設定項目をフラットなカード状に表示するモダンなレイアウト。
- **構成要素:** 
  - **一般タブ:** 言語切り替え、アラーム時刻変更時の自動有効化設定
  - **外観タブ:** テーマ切り替え（ライト / ダーク）
  - **サウンドタブ:** 通知音の音量調整（スライダー）、アラーム音の変更（プルダウンと隣接するプレビューボタン）、オリジナル通知音のアップロードボタン
  - **概要タブ:** GitHubリンク、タイマー・アラーム音（OtoLogic）の素材元リンクと権利者表記の表示
- **画面操作:** 画面右上に常に固定で配置される「×」ボタン（閉じるボタン）を提供し、直感的にページを閉じることができるようにする。設定画面のタブのみしか開かれていない場合はページを一つ戻る（履歴を戻る）動作とする。
- **デザイン:** メイン画面と共通のモダンなデザイン（十分な余白、角丸）を使用し、テーマ（ライト/ダーク）も連動する。枠線や影を抑えたフラットなUIを採用し、カスタムデザインのプルダウンメニューを使用する。

## 2. カードデザイン
デザインの統一感を重視し、タイマーとアラームで基礎的なレイアウトを共有する。手書きのデザイン案をモダンにブラッシュアップして実装する。

### 2.1. 共通要素
- **ベース:** わずかなドロップシャドウと角丸を持つカードコンテナ。
- **左上:** タイトル（ワンクリックで編集可能なインラインテキストボックス化）。
- **右上:** 削除（×）ボタン。
- **インタラクション:** カード自体をつかんでドラッグ＆ドロップで並べ替え可能（タイトル編集中は無効化）。

### 2.2. タイマーカード固有要素
- **中央:** 大きな文字での時間表示（`00:00` または `00:00:00`）。クリックすると入力モードになり、数値入力による自動変換（スマート入力）を受け付ける。
- **右下:** リセットボタンと再生/ストップボタン。リセットボタンは再生/ストップボタンの左横に配置され、共通のデザインを使用する。リセットボタンはデフォルトで非表示であり、タイマーが動作中、または現在の数値が初期設定値から変更されている場合のみ表示される。カウントダウン中は再生ボタンがストップ（一時停止）ボタンに変化する。

### 2.3. アラームカード固有要素
- **中央:** 大きな文字での時刻表示（`HH:MM`）。
- **右側:** 有効/無効を切り替えるトグルスイッチ（ON時はオレンジ色）。
- **サマリー表示（折りたたみ時）:** 曜日が指定されている場合やメモが入力されている場合は、詳細設定を開かなくてもカード上にそれらの情報を表示する（メモが長文の場合は末尾を省略表示する）。
- **今日をスキップテキスト:** 曜日指定が有効であり、かつ今日アラームが鳴る予定となっている場合、省略表記の曜日（サマリー表示）の上部に「今日をスキップ」というテキスト（ボタンとして機能、下線なし、アクセントカラー）を表示する。詳細設定を開かなくてもアクセス可能であり、一度アラームを無効にするとスキップ状態は解除される。
- **詳細設定（折りたたみUI）:**
  - カード内に「詳細設定」や「下向き矢印」などのトグルボタンを配置する。
  - ボタンを押下するとカードが下部に展開し、左揃えで配置された曜日指定UI（月曜から日曜までの丸いアイコン）およびメモの入力フィールドが表示される。これにより、通常時はカードをコンパクトに保ち、UIの煩雑さを防ぐ。
## 3. 通知UIデザイン
- **アクティブタブ表示時（独自ポップアップ）:**
  **画面上部から下へスライドインしてくる**視覚的に目立つ独自UI（トースト通知のような形式）。
  「タイトル」「設定時間（または時刻）」「ストップボタン」を配置し、メインUIとトンマナを合わせる。ストップボタンにはアクセントカラーのオレンジを使用する。
- **非アクティブ時（システム通知）:**
  OSの標準通知UIに従う。タイトルとメッセージテキストを表示し、「ストップ」アクションボタンを提供する。通知自体をクリックした場合でもアラームが停止し、ブラウザが最前面に復帰する。
