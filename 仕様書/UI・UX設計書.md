# UI・UX設計書 (Time Alert)

## 1. 全体画面構成（サイドパネル）
メインUIはChromeの**サイドパネル**（`chrome.sidePanel`）内で提供される。横幅一杯を使用する。

### 1.1. 共通レイアウトとデザイン方針
- **デザインスタイル:** 現在主流のモダンなフラットデザイン、またはニューモーフィズム要素を取り入れたクリーンなUI。十分な余白（パディング）、角丸（border-radius）、控えめなシャドウを用いて洗練された印象を与える。
- **カラーパレット:** アクセントカラーに**オレンジ**を採用。再生ボタン、トグルボタンのON状態、アクティブなタブ表示などにオレンジを使用し、視覚的なコントラストとアクションを促す。
- **ヘッダー部:** タブ切り替え（「タイマー」 / 「アラーム」）。
- **メインコンテンツ部:** カードリスト領域（縦スクロール）。
- **フローティングアクション:** 右下固定の「＋」ボタン（新規カード追加）。アクセントカラーのオレンジを目立たせる。

### 1.2. テーマ
- ライトモードとダークモードの2種類を作成。
- デフォルトはOSまたはブラウザのシステム既定値（`prefers-color-scheme`）に自動で追従する。

## 2. カードデザイン
デザインの統一感を重視し、タイマーとアラームで基礎的なレイアウトを共有する。手書きのデザイン案をモダンにブラッシュアップして実装する。

### 2.1. 共通要素
- **ベース:** わずかなドロップシャドウと角丸を持つカードコンテナ。
- **左上:** タイトル（ダブルクリックで編集可能なインラインテキストボックス化）。
- **右上:** 削除（×）ボタン。
- **インタラクション:** カード自体をつかんでドラッグ＆ドロップで並べ替え可能。ホバー時に少し浮き上がるようなアニメーションをつける。

### 2.2. タイマーカード固有要素
- **中央:** 大きな文字での時間表示（`00:00` または `00:00:00`）。クリックすると入力モードになり、数値入力による自動変換（スマート入力）を受け付ける。
- **右下:** 再生/ストップボタン。カウントダウン中はストップ（リセット）ボタンに変化する。

### 2.3. アラームカード固有要素
- **中央:** 大きな文字での時刻表示（`HH:MM`）。
- **右側:** 有効/無効を切り替えるトグルスイッチ（ON時はオレンジ色）。
- **詳細設定（折りたたみUI）:** 
  - カード内に「詳細設定」や「下向き矢印」などのトグルボタンを配置する。
  - ボタンを押下するとカードが下部に展開し、曜日指定UI（月曜から日曜までの丸いアイコン）が表示される。これにより、通常時はカードをコンパクトに保ち、UIの煩雑さを防ぐ。

## 3. 通知UIデザイン
- **アクティブタブ表示時（独自ポップアップ）:**
  **画面上部から下へスライドインしてくる**視覚的に目立つ独自UI（トースト通知のような形式）。
  「タイトル」「設定時間（または時刻）」「ストップボタン」を配置し、メインUIとトンマナを合わせる。ストップボタンにはアクセントカラーのオレンジを使用する。
- **非アクティブ時（システム通知）:**
  OSの標準通知UIに従う。タイトルとメッセージテキストを表示し、「ストップ」アクションボタンを提供する。
