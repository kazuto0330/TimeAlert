# 要件定義書 (Time Alert)

## 1. 概要
本拡張機能は、Chromeブラウザ上で動作し、ユーザーに直感的なタイマーとアラーム機能を提供する。UIはサイドパネルで提供され、複数のタイマー・アラームの同時管理、音声のカスタマイズ、端末間のデータ同期を特徴とする。

## 2. コア機能

### 2.1. タイマー機能
- **設定・実行:** ユーザーが時間を設定し、再生ボタンでカウントダウンを開始する。複数タイマーの同時実行が可能。
- **通知:** カウントが0になった際、音声と視覚的ポップアップで通知する。
- **リセット:** 通知のストップボタン、または実行中のストップボタンを押下すると、ユーザーが設定した時間に戻り、カウントダウンが停止する。
- **時間表示フォーマット:**
  - 基本: `MM:SS` (分:秒) 例: `12:30`
  - 1時間を超える場合: `HH:MM:SS` (時:分:秒) 例: `01:30:00`
- **入力補完（スマート入力）:**
  - 全角・半角入力に対応。
  - 数値のみが入力された場合、末尾から秒、分、時として自動変換する（電子レンジ方式）。
  - 例: `90` → 90秒 → `01:30` (1分30秒)
  - 例: `1230` → 12分30秒 → `12:30`
  - 例: `9000` → 90分00秒 → `01:30:00` (1時間30分)

### 2.2. アラーム機能
- **設定・有効化:** ユーザーが時間（`HH:MM`、時:分）を設定し、トグルボタンで有効化する。
- **通知:** 指定した時刻になった際、音声と視覚的ポップアップで通知する。
- **停止・無効化:** 通知のストップボタンを押下すると、音声が止まりポップアップが閉じ、対象のアラームが無効化（トグルOFF）される。
- **繰り返し（曜日指定）:**
  - 任意の曜日を単一または複数指定可能。
  - 曜日が指定されている場合、通知のストップボタンを押下してもアラームは無効化されず、次の該当曜日のタイミングに向けてアクティブなまま維持される。
  - **UIの簡略化:** 曜日指定の設定領域はデフォルトでは折りたたまれており、カード上の展開ボタン（歯車アイコンやドロップダウン矢印など）を押下した時のみ表示される。

### 2.3. 通知・音声システム
- **ハイブリッド通知:** Chromeのアクティブ状態に応じて通知方法を自動的に切り替える。どちらも「ストップ（通知停止）」アクションを持つ。
  1.  **ブラウザがアクティブなタブの場合:** 拡張機能内の独自UI（画面上部からのスライドイン）を表示する。
  2.  **ブラウザがアクティブでない（別のアプリを見ている等）場合:** OSのシステム通知（`chrome.notifications`）を表示する。
- **デフォルト音声:** タイマー・アラーム共通のデフォルト音源（`sounds/Clock-Alarm01-1(Low-Loop).mp3`）を使用する。

### 2.4. 設定機能
設定画面はサイドパネルから独立した専用のオプションページ（別タブ）として表示する。設定項目は機能ごとにタブ（一般、外観、サウンド）で分類され、以下の項目を設定可能とする。
1. **言語切り替え (一般タブ):** 日本語と英語の2種類。初期値はシステムのデフォルト言語。
2. **アラーム時刻変更時の自動有効化 (一般タブ):** アラームの時刻を変更した際に、自動でアラームを「ON」にするかどうかの設定（ON/OFF切り替え可能、初期値はON）。
3. **テーマ切り替え (外観タブ):** ライトモードとダークモードの2種類。
4. **通知音の音量調整 (サウンドタブ):** スライダーバーで調整可能。初期値は50%。
5. **アラーム（通知）音の変更 (サウンドタブ):** プルダウンメニュー形式で、デフォルト音源を含む複数のプリセットから選択可能。
6. **オリジナル通知音のアップロード (サウンドタブ):** ユーザーが所有する音声ファイル（mp3等）をアップロードし、通知音として使用できる機能。

## 3. カード管理・UI機能
タイマーとアラームは「カード」として視覚的に管理される。
- **タブ切り替え:** タイマーとアラームの画面はタブで切り替える。
- **新規作成:**
  - サイドパネル右下の「＋」ボタンを押下して作成。
  - 現在表示しているタブ（タイマーまたはアラーム）の新規カードが作成される。
  - 新規カードはリストの一番上に追加される。
- **タイトル編集:**
  - デフォルト名: `[機能名] + [連番]` (例: `タイマー1`, `タイマー2`)。連番は既存の番号と重複しないように自動採番される。
  - タイトル部分をクリック（ワンクリック）するとテキスト入力エリアになり、ユーザーが自由に名称を変更できる。テキストの選択操作と競合しないよう、編集中はドラッグ＆ドロップによる並べ替えが無効になる。
- **削除:** カード右上の「×」ボタンで削除。
- **並び替え:** カードをマウスでドラッグ＆ドロップし、自由に順序を入れ替え可能。

## 4. データ・状態管理
- `chrome.storage.sync` を使用し、ユーザーが作成したタイマー/アラームの設定やリストを同じGoogleアカウント間で自動的に同期する。
- （※アップロードした音声ファイルなどの大容量データは、同期制限を考慮してローカルストレージへの保存を検討する。）
